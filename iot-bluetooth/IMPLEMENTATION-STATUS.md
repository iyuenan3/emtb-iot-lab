# 功能实现状态

当前 iPhone App 基线为 Build 21，目标是一个纯蓝牙、单连接单动作的最小车钥匙。

## 已完成

| 范围 | 状态 |
| --- | --- |
| 单页界面 | 只显示手动连接、长按开锁、长按关锁、结果提示、密钥和本机诊断 |
| BLE 连接 | 只扫描配置的设备、发现 NUS 服务并使用 8 字节设备密钥认证 |
| 控制协议 | 活跃命令白名单只有认证 `0x01`、开锁 `0x05`、错误 `0x10`、关锁 `0x15` |
| 单次动作 | 每次连接只能选择开锁或关锁一次，不能在同一连接反向操作 |
| 结束策略 | 收到设备结果后发送同命令 `0x02` 必要回执，写入完成后立即主动断开 |
| 失败策略 | 8 秒超时、写入失败或提前断连都标记为结果未知，不重连、不重试 |
| 本机安全 | 开关锁和密钥变更都要求 Face ID 或设备密码，密钥保存在 iOS Keychain |
| 构建目标 | 远程控制、BLE 事件上传和维护页面已从 Xcode Target 移除 |
| 自动验证 | 7 项源码守卫通过，通用 iOS 设备目标无签名编译通过 |

旧的远程服务和研究代码仍保留在仓库中，便于审计和恢复历史，但不进入 Build 21 App。此前部署的 `iot-remote` revision `469f154b75bb243e61cd1dd3f291fde0256bb7bb` 没有在本轮修改或重新部署。

## 明确取消的 App 功能

- 远程状态、地图、轨迹、告警、指令记录和服务设置
- 自动读取 `0x31` 锁态、`0x60` 骑行数据和 `0xFA` 系统信息
- 自动重连、自动刷新、自动状态同步和离线事件补报
- 车辆设置、RFID、外部锁、服务器、APN、日志读取、旧数据清理和 OTA
- 根据 BLE 回读推断实际锁态

## 尚未完成

1. Build 21 签名编译和真机安装。
2. 新界面的人机检查，包括长按、Face ID 取消路径和诊断文字。
3. 只连接不控制的稳定性验收。
4. 单次开锁后的仪表、动力和轮毂锁验收。
5. 从全新连接执行单次关锁后的仪表、动力和轮毂锁验收。

上述实车步骤需要用户在车辆旁人工确认。代码、测试、编译和安装都不能代替物理验收。
