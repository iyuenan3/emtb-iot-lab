# 权限与安全

## iPhone 权限

Build 33 只申请 Bluetooth 权限，用于用户长按后扫描、认证和控制指定车辆。它不申请 Face ID、定位、通知、文件或网络权限。

## 凭据

- 设备密钥必须是 8 个 ASCII 字节，保存在新的 iOS Keychain 服务中。
- Keychain 项使用仅本机、设备解锁时可访问的保护级别。
- 连接 Key 只存在于当前连接内存，断开即清除。
- App 不回显、记录或上传密钥。
- `.env.local` 的 `BLE_KEY` 只供 MacBook 工具使用，不会进入 App 包。
- `DEVICE_BLE_MAC` 由被 Git 忽略的 `Secrets.xcconfig` 注入。

## 操作保护

- 开锁和关锁均需长按 1.2 秒。
- 操作期间两个按钮都不可用。
- 一次操作只发送一条主控制指令。
- 失败后停止并断开，不自动重连、不自动重试、不反向补发。
- 协议成功后仍提示用户核对仪表和晃动报警。
