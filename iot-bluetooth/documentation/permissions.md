# 权限与安全

## iPhone 权限

| 权限 | 用途 | 触发时机 |
| --- | --- | --- |
| Bluetooth | 扫描、认证、查询和控制指定车辆 IoT | 用户点击连接时 |

Build 24 不申请 Face ID、定位、通知、文件选择或网络相关权限。

## 凭据

- 8 字节 ASCII 设备密钥保存在 iOS Keychain，并使用仅本机、解锁时可访问的保护级别。
- App 不回显、不上传、不记录设备密钥或认证连接 Key。
- Mac `.env.local` 的 `BLE_KEY` 不会自动进入 iPhone App 或 App 包。
- 目标 IMEI 和 BLE MAC 由被 Git 忽略的 `Secrets.xcconfig` 注入，真实值不得提交。

## 操作保护

- 主锁开锁和关锁必须长按 1.2 秒，并用当前主锁状态阻止重复动作。
- 基础设置和高级设置在发送前显示确认框。高级设置额外校验限速范围，并明确提示掉电保存影响。
- 旧骑行数据必须先读取才能清除，清除前提示先保存数据并要求二次确认。
- 外部锁查询是只读操作；解锁和上锁需要二次确认，并在设备接受后查询状态。
- 所有协议操作串行执行，操作中禁用其他按钮，避免无命令序号回包串线。
- 结果未知时立即停止并断开，不重试、不补发、不自动重连。
- 关锁、参数修改和外部锁操作前必须确认车辆静止，操作后检查对应物理状态。

## 诊断与隐私

诊断记录只保存在当前 App 进程内，最多 120 条，可由用户主动分享。诊断不包含密钥、认证连接 Key、完整设备标识、旧骑行用户 ID、位置或服务器信息。旧骑行用户 ID 只在用户主动读取后显示，并只通过单独的旧数据分享入口导出。
