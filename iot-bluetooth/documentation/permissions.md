# 权限与安全

## iPhone 权限

| 权限 | 用途 | 触发时机 |
| --- | --- | --- |
| Bluetooth | 扫描、认证和单次控制指定车辆 IoT | 用户点击连接时 |
| Face ID 或设备密码 | 保护开锁、关锁和设备密钥变更 | 每次敏感操作前 |

Build 21 不申请定位、通知、文件选择或网络相关权限。

## 凭据

- 8 字节 ASCII 设备密钥保存在 iOS Keychain，并使用仅本机、解锁时可访问的保护级别。
- App 不回显、不上传、不记录设备密钥。
- Mac `.env.local` 的 `BLE_KEY` 不会自动进入 iPhone App 或 App 包。
- 目标 IMEI 和 BLE MAC 由被 Git 忽略的 `Secrets.xcconfig` 注入，真实值不得提交。

## 控制保护

- 开锁和关锁必须长按 1.2 秒并通过设备所有者验证。
- 每次连接最多一个动作，不能在同一连接中从开锁切换为关锁或反向切换。
- App 不读取锁态来决定按钮或宣称物理成功。
- 结果未知时立即停止，不重试、不补发、不自动重连。
- 关锁前必须确认车辆完全静止，操作后必须检查仪表、动力和轮毂锁。

诊断记录只保存在当前 App 进程内，最多 100 条，不包含密钥、完整设备标识、位置或服务器信息。
