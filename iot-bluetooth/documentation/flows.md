# 关键流程

## 连接

1. 用户点击“连接车辆”。
2. App 扫描与配置 BLE MAC 对应的 manufacturer data。
3. App 连接设备，只发现配置的 NUS 服务和读写特征。
4. App 从 Keychain 读取 8 字节设备密钥并发送认证。
5. 认证成功后显示“蓝牙已就绪”，不读取任何车辆状态。

连接不会由 App 自动发起。断开后也不会自动重连。

## 开锁或关锁

1. 用户在已认证连接中长按一个按钮 1.2 秒。
2. 系统要求 Face ID 或设备密码。
3. App 将该连接标记为已经尝试动作，并发送一次 `0x05` 或 `0x15`。
4. App 等待对应命令的设备结果，不响应另一种控制结果。
5. 收到已识别结果后，App 发送同命令的 `0x02` 必要回执。
6. 回执写入完成后，App 立即主动断开 BLE。
7. 用户根据仪表、动力和轮毂锁判断实际结果。

## 异常

- 8 秒内未完成结果与回执流程：显示结果未知并断开。
- BLE 写入失败：显示结果未知并断开。
- 控制期间连接提前断开：显示结果未知，不重连、不重试。
- 设备返回协议错误或明确拒绝：显示未完成并断开。
- 同一连接再次操作：本地拒绝，不发送任何帧。

## 首次实车验收

首次验收分成三个独立连接：只连接后断开、单次开锁、单次关锁。每一步之间等待并确认车辆完全稳定。禁止连续切换开关锁来测试界面状态。
