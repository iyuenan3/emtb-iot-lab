# App 界面设计

## 设计目标

Build 24 是户外单手可用的纯蓝牙车辆工具。日常开关锁保持最短路径，设置、数据和外部锁放入独立页面，避免高风险功能挤占车钥匙入口。

## 三页结构

### 车钥匙

1. 连接卡显示 BLE 阶段、信号、主锁状态和最近回读时间。
2. 手动连接、刷新和断开按钮不会自动触发 BLE。
3. 开锁和关锁使用两个大按钮，均需长按 1.2 秒。
4. 结果卡区分发送中、回包与回读一致、设备拒绝和结果未知。
5. 密钥入口只处理 8 字节设备密钥。

### 车辆

1. 状态卡展示电量、骑行模式、速度、本次里程、剩余里程、锁电压和固件版本。
2. 基础设置提供前灯、模式、油门和尾灯，默认均为“不修改”。
3. 高级设置提供掉电保存、巡航、启动方式和三档限速。
4. 两组设置都先汇总用户选择，再由确认框发送，不在选择控件变化时立即写入设备。

### 工具

1. 旧骑行数据必须先读取，用户可以分享保存，再二次确认清除。
2. 电池锁、车轮锁和钢缆锁分别提供查询、解锁和上锁。
3. 外部锁查询是只读操作，解锁和上锁需要二次确认。
4. 脱敏诊断默认折叠，只由用户主动分享。

## 视觉与交互

- 橙色用于开锁和需注意的状态，靛蓝用于主关锁，红色用于失败、未知结果和破坏性确认。
- 连接状态同时使用图标和文字，不只依赖颜色。
- 未连接或已有操作进行时，所有协议按钮不可用。
- 设置项用“不修改”作为默认值，避免误触进入写操作。
- App 不显示“开锁成功”或“关锁成功”，只描述设备回包和协议状态回读是否一致。
- 使用系统字体、Dynamic Type 和 SF Symbols，不引入网络图片或第三方 UI 依赖。

## 明确不进入当前界面

远程状态、地图、轨迹、告警、云端记录和服务设置不进入 Build 24。系统信息、日志、RFID、电源、服务器、APN 和 OTA 虽然出现在部分归档工具中，但不属于 V1.2.5 文档的正式 BLE 功能清单，因此也不提供隐藏入口。
