# App 界面设计

## 设计目标

Build 23 是户外单手使用的最小蓝牙车钥匙。界面只回答四个问题：是否已经连接、设备回读的锁态是什么、现在能否执行一次动作、操作后需要检查什么。

## 单页结构

1. 连接卡：显示 BLE 阶段、信号和手动连接或断开按钮。
2. 控制卡：并列显示开锁和关锁两个大按钮，均需长按 1.2 秒。
3. 结果卡：区分发送中、设备已接收、设备未完成和结果未知。
4. 安全卡：固定提示以仪表、动力和轮毂锁的物理结果为准。
5. 诊断记录：默认折叠，只保存当前进程的脱敏事件，并可分享文本用于排障。
6. 密钥页：由右上角入口打开，只处理 8 字节设备密钥。

## 视觉与交互

- 橙色用于开锁，靛蓝用于关锁，红色只用于失败和未知结果。
- 连接状态同时使用图标和文字，不只依赖颜色。
- 控制按钮提供足够大的长按区域，并在按压时轻微缩放。
- 未连接、控制中或同一连接已操作时，控制按钮不可用。
- App 不显示“开锁成功”或“关锁成功”，只显示设备协议是否已接收。
- 使用系统字体、Dynamic Type 和 SF Symbols，不引入网络图片或第三方 UI 依赖。

## 已删除的信息架构

Build 20 及更早的车辆、地图、记录、更多四页结构不再使用。远程状态、轨迹、告警和维护功能不会以隐藏入口留在当前 App。Build 23 只恢复 Build 2 已验证过的主锁状态读取，不恢复电量、系统信息或维护读取，也不包含 Face ID 授权路径。
