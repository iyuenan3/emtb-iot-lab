# App 界面设计

## 设计目标

Build 25 是户外单手可用的纯蓝牙车辆工具。日常开关锁保持最短路径，车辆状态、旧数据和诊断放入独立页面，不可靠设置和外部锁没有操作入口。

## 三页结构

### 车钥匙

1. 连接卡显示 BLE 阶段、信号、主锁状态和最近回读时间。
2. 手动连接、刷新和断开按钮不会自动触发 BLE。
3. 开锁和关锁使用两个大按钮，均需长按 1.2 秒。
4. 结果卡区分发送中、回包与回读一致、设备拒绝和结果未知。
5. 密钥入口只处理 8 字节设备密钥。

### 车辆

1. 状态卡展示电量、骑行模式、速度、本次里程、剩余里程、锁电压和固件版本。
2. 页面明确说明 `0x61` 和 `0x62` 已根据实车结果停用。

### 数据与诊断

1. 旧骑行数据必须先读取，用户可以分享保存，再二次确认清除。
2. 页面明确说明三类 `0x81` 外部锁功能已停用。
3. 脱敏诊断默认折叠，只由用户主动分享。

## 视觉与交互

- 橙色用于开锁和需注意的状态，靛蓝用于主关锁，红色用于失败、未知结果和破坏性确认。
- 连接状态同时使用图标和文字，不只依赖颜色。
- 未连接或已有操作进行时，所有协议按钮不可用。
- App 不显示“开锁成功”或“关锁成功”，只描述设备回包和协议状态回读是否一致。
- 使用系统字体、Dynamic Type 和 SF Symbols，不引入网络图片或第三方 UI 依赖。

## 明确不进入当前界面

远程状态、地图、轨迹、告警、云端记录和服务设置不进入 Build 25。`0x61`、`0x62`、`0x81` 以及系统信息、日志、RFID、电源、服务器、APN 和 OTA 都不提供隐藏入口。
